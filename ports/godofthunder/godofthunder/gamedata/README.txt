Download the original freeware game manually:
https://www.adeptsoftware.com/got/gotfree.zip

Extract ALL files from gotfree.zip directly into this gamedata folder.
GOTRES.DAT and GOT.EXE must be directly inside gamedata, not in another folder.
Then launch God of Thunder from Ports.

The port does not download game data. No internet connection is required to play.
The native engine reads GOT.EXE only as a container for graphics and menu data.
It never executes the original DOS programs and does not use an emulator.

Your existing GOTSAVE1.SAV, GOTSAVE2.SAV, GOTSAVE3.SAV and GOT.CFG remain in the
parent godofthunder folder, not in gamedata.
