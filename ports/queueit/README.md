## Notes

Queue-it is made by [Leo Imbert](https://leo-imbert.itch.io/).

## Controls

| Button | Action |
|--|--| 
|DPAD/LEFT STICK|Move|
|B|Use first gem in queue|
|X|Restart the level|
|Y|Interact (doors, signs)|

## Extra controls

| Button | Action |
|--|--| 
|A+B+X+Y+DL|Toggle screen scaling between maximum and integer|
|A+B+X+Y+DR|Switch between screen modes (Crisp/Smooth/Retro)|
|A+B+X+Y+DU|Toggle the performance monitor (FPS/update time/draw time)|
|A+B+X+Y+DD|Toggle fullscreen|
