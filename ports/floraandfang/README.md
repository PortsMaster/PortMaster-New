## Controls

| Button | Action |
|--|--| 
|DPAD / Left Stick|Move|
|A|Confirm / Jump|
|B|Cancel / Use Trap|
|X|Spray|
|Y|Pick Up / Drop|
|Shoulders|Switch Trap|
|Start|Pause menu|
