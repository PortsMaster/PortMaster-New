# korean-name-input

La pantalla del nombre con un teclado coreano, para escribirlo con el mando.
Funciona con o sin el parche coreano.

**A** escribe, **B** borra, **L1** / **R1** cambian de página (한글, ABC,
abc) y **확인** termina.

La letra coreana es Noto Sans CJK KR (licencia OFL, en `licenses/`).

No viene activo. Para ponerlo: `korean-name-input: On` en la opción Mods del
launcher del port.
