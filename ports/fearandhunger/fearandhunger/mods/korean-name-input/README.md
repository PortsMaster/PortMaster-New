# korean-name-input

The name screen with a Korean keyboard, to type it with the gamepad. It
works with or without the Korean patch.

**A** types, **B** deletes, **L1** / **R1** change the page (한글, ABC, abc)
and **확인** ends.

The Korean font is Noto Sans CJK KR (OFL license, in `licenses/`).

It does not come on. To turn it on: `korean-name-input: On` in the Mods
option of the launcher of the port.
