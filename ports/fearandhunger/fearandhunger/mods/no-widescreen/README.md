# no-widescreen

Turns off the widescreen of a widescreen mod (like "Widescreen y Español",
Nexus 205), so the game keeps its original size, 816x624. On the square
screens of many handhelds the game then looks bigger.

## Order

It must have a higher number than the widescreen mod in the Mods option of
the menu of the port. Turn the widescreen mod On first, then this one:

```
es205: On (1)
no-widescreen: On (2)
```

If it has the lower number, the widescreen mod wins and nothing changes.
Without a widescreen mod, this mod does nothing.
