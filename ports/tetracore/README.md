## Controls

| Button | Action |
|--|--| 
|D Pad Up|move up|
|D Pad Down|move down|
|D Pad Left|move left|
|D Pad Right|move right|
|Rotate Core|A|
|Back In Menu|B|
|Speed Up|X|
|Rotate Shape|Y|
|Start|pause|


- controls are fully bindable in game
