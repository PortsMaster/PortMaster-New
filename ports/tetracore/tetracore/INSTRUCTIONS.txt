INSTRUCTIONS

1. Put the launch script (tetracore.sh) wherever it needs to go.
	- example, in ROCKNIX it goes in STORAGE/games-internal/roms/ports

2. ensure that the launch script is executable.
	- can right click the file and make it executable as a program
	- or open a terminal window wherever the file is and run 'chmod +x tetracore.sh'

3. Put the tetracore folder wherever it needs to go.
	- example, in ROCKNIX it goes in STORAGE/games-internal/roms/ports

4. Download the .love file from https://firns.itch.io/tetracore

5. put it in /tetracore/gamedata
	- example, in ROCKNIX it goes in STORAGE/games-internal/roms/ports/tetracore/gamedata

It should be ready to run via ports! Enjoy!
