## Controls

| Button | Action |
|--|--| 
|Controls: D-pad / L-stick|Movement|
|A|Jump / Select|
|B|Spell / Back|
|X|Attack|
|Y|Special|
|L2 / R2|Dash Left / Right|
|Start|Pause / Menu|
|Select|Map|
