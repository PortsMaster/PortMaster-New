Source: https://allegator.sourceforge.net/a4maps/ (12 packs) and the archived
http://alex4.webz.cz/ fan site via Wayback Machine snapshot 20031216165713 (11 packs,
one dead link `dmnalex.zip` on that mirror skipped - identical file already present from
the live a4maps page). One near-duplicate (`superhard.zip` on webz.cz - identical
readme text to `super_hard` from a4maps, different map file bytes, presumed a stray
re-upload of the same pack) was dropped to avoid shipping the same content twice.

All are fan-made GPL-era-community levels for the GPLv2 game itself; distribution terms
below are only what each author actually wrote - most gave no explicit statement (common
for 2003 fan content hosted on the game's own community map page), a few gave explicit
