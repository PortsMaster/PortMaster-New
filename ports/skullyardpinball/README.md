## Controls

| Button | Action |
|--|--| 
|DPAD / Left Stick / A / Y|Paddles|
|A|Confirm (menu)|
|B|Cancel|
|X|Launch ball|
|R1/L1|Shake table|
|Select / Start|Pause|
