## CONTROLS

| Button | Action |
|--|--| 
|Dpad|Move Camera|
|Right Stick/Left Stick|Move Cursor|
|R1|Select (as if a mouse press)|
|L1|Deselect all selected units|
|Select or Start| Pause the game|
