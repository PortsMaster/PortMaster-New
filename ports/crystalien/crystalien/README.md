## Notes

Real Time Strategy on the red planet! A conflict between aliens and astros! An iconic toy brand from 2007!
A Crystalien Conflict Remake made in the Godot game engine. (Crystalien Conflict was a cult classic flash game made by the Lego group to promote the "Mars Misson" toyline, with gameplay similar to Command & Conquer. Special thanks to B1er0l14m sharing the source code and agreeing to let the game be ready-to-run.

Notable that this is a 3:2 aspect ratio game, so it's a perfect fit for some of those 3:2 handhelds.

## Controls

| Button | Action |
|--|--| 
|D-pad|Move Camera|
|Either Thumbstick|Move Cursor|
|R1|Click to select|
|L1|Click to deselect|
|Start|Pause|
|Select|Skip cutscene|
