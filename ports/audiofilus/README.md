## Notes
A music player that keeps playing while you game: close the app in the background, or press Start twice (or close the lid) for a screen-off sleep mode that barely uses battery.

On first start, pick the folder with your music (any folder on the SD card); you can change it later in Settings. Also plays internet radio, podcasts, and music from Subsonic/Jellyfin servers.

Source and documentation: https://github.com/juanvillacortac/audiofilus

Uses libgme (LGPL 2.1), libvgm (GPL 2.0) and libfdk-aac. Their licenses and those of the fonts are in `audiofilus/licenses`.

## Controls
| Button | Action |
|--|--|
| A / Y | Pause / resume |
| D-pad left / right | Tap: previous / next song. Hold: seek |
| L1 / R1 | Previous / next song, from any screen |
| L2 / R2 | Seek back / forward 10 s |
| X | Shuffle on / off (twice: a random song) |
| B | Back |
| Start | More options |
| Select | Screens bar (twice: previous screen) |
| FN (hold) | Controls guide |
| Start ×2 | Sleep: screen off, music on (Start wakes it) |
