================================================================================
👑 STATION NORTH SNfetchPLAYER • ONLINE JSON PLAYLISTS
================================================================================

This directory houses online streaming stations and custom JSON playlists.
SNfetchPLAYER comes preloaded with curated late-night channels:
• main_top100.json       -> Station North • Main Top 100
• us_hiphop_top50.json   -> Station North • US Hip-Hop Top 50
• us_rnb_top50.json      -> Station North • US R&B Top 50

--------------------------------------------------------------------------------
📱 INTEGRATION WITH THE STATION NORTH ANDROID APP:
--------------------------------------------------------------------------------
Did you know you can curate your favorite songs on your smartphone?
Check out the official Android Companion App:
👉 https://github.com/StationNorthMedia/SNfetchPLAYER

1. Build or export your custom playlist JSON from the Android app.
2. Drop the .json file directly into this /playlists/ folder.
3. Open SNfetchPLAYER -> Settings -> "Re-Scan Local Asset Storage".
4. Your new station is instantly ready to play!

--------------------------------------------------------------------------------
📝 JSON PLAYLIST FORMAT:
--------------------------------------------------------------------------------
Custom JSON playlists follow this simple format:

[
  {
    "youtubeId": "eXvBjCO19QY",
    "title": "Changes",
    "artist": "2Pac ft. Talent"
  },
  {
    "youtubeId": "GxBSyx85Kp8",
    "title": "Yeah!",
    "artist": "Usher ft. Lil Jon"
  }
]

--------------------------------------------------------------------------------
💡 ONLINE STREAMS IN RADIO VS. TV MODE:
--------------------------------------------------------------------------------
• ALL online tracks can be enjoyed in BOTH Radio and TV mode!
• IN TV MODE: Streams the official video with 4:3 fit and retro lower-thirds.
• IN RADIO MODE: Extracts only the lightweight audio stream, saving bandwidth
  and battery while powering the 60 FPS spectrum analyzer.
• TIP: Many YouTube tracks are lyric videos, visualizers, or static album covers.
  Radio Mode is the ideal way to enjoy them without wasting system resources!

The frequency is always live. 👑✨
