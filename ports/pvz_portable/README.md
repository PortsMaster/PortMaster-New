# Notes
Plants vs. Zombies Portable running on Linux handheld devices via PortMaster.

## Installation
- Provide the `main.pak` file and `properties/`  folder from a legal copy of Plants vs. Zombies GOTY into the `pvz_portable/` folder.
- Save data and mid-level saves are located in the `userdata` directory.

## Controls

| Button       | Action                                                                                        |
| --------------| -----------------------------------------------------------------------------------------------|
| A            | Click/place plant                                                                             |
| B            | Grab shovel/cancel shovel                                                                     |
| X            | Whack a zombie in the minigame of the same name / pull the lever in the slot machine minigame |
| Select       | Pause game                                                                                    |
| DPAD         | Move virtual cursor                                                                           |
| Any joystick | Move virtual cursor                                                                           |
| L1           | Select previous seed packet                                                                   |
| R1           | Select next seed packet                                                                       |
