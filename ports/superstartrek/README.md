## Controls

| Button               |  Action                          |
|----------------------|----------------------------------|
| Select               | Menu/Cancel                      |
| Start                | Confirm                          |
| DPad Up              | Increase Energy/Shields          |
| DPad Down            | Decrease Energy/Shields          |
| DPad Left            | Cycle Commands Left              |
| DPad Right           | Cycle Commands Right             |
| A                    | Select/Confirm                   |
| B                    | Communications/Docking           |
| SELECT + B           | Damage Report                    |
| Y                    | Long-Range Sensors               |
| SELECT + Y           | Science/Status Report            |
| X*                   | Shields                          |
| SELECT + X           | Galactic Map                     |
| L1                   | Impulse Speed Navigation         |
| L2                   | Warp Speed Navigation            |
| R1                   | Torpedoes                        |
| R2                   | Phasers                          |
| Left Analog          | Mouse                            |
