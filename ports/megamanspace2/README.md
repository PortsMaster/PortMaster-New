## Controls

| Button | Action |
|--|--| 
|A button|shoot|
|B button|shoot|
|L1|shoot|
|R1|shoot|
|Dpad|player movement|
|Left analog stick |player movement |
|Right analog stick |aim ship/gun|
|Start button|Start/Pause|
