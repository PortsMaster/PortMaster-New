## The Last Summer: Prologue 1.4.0

The free Prologue (Chapters 1 to 3) of a cozy isometric story game about a seaside hotel
closed for twenty years. The full game is on itch.io (https://tri2510.itch.io/the-last-summer); a
Prologue save carries over. Freeware: share unmodified copies free of charge
(thelastsummerprologue/licenses/LICENSE.txt). The first start unpacks the game data, which takes a moment.


## Controls

| Button | Action |
|--|--|
| D-pad / left stick | Walk, move in menus |
| A | Talk, look, use, confirm |
| B | Back, stop fishing, stand up |
| X or R1 (hold) | Run |
| Select (or Y, until Nell has a camera) | Notebook |
| Y (with the camera) | Look through the camera; A takes the photo |
| Start | Pause menu |

Needs a screen of at least 640x480. Saves are kept in thelastsummerprologue/saves/.
