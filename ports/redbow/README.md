## Notes

Thanks to [Stranga Games](https://store.steampowered.com/search/?developer=Stranga%20Games) for developing this game. You can buy it on [Steam](https://store.steampowered.com/app/710600/Red_Bow/).

Runs on the AGS (Adventure Game Studio) engine, same setup as the My Big Sister port by Ganimoth.

## Controls

| Button | Action |
|--|--|
|Dpad / Left stick|Movement|
|A|Action|
|B|Cancel|
|X|Inventory|
|Start / Select|Menu / Skip cutscene|

## Install

Copy all game files from your purchased copy into the `gamedata` folder.
