* 

**Note on performance and RAM:**

The game is demanding and a more powerful devices like `Mangmi Air X` or `Odroid Go Ultra` and better are strongly recommended. Also on `1GB` devices, it is recommended to restart the game after any longer run to free memory, to avoid running out of memory in subsequent runs. Enabling ZRAM is recommended if available.

## Controls

|Button|Action|
|-|-|
|DPAD / Left Stick|Movement / Cursor (Stick)|
|Right Stick|Aim|
|A|Accept|
|L1|Sneak|
|R1|Blackhole Bomb|
|L2|Toggle Autoaim|
|R2|Fast Forward|
|Start|Menu|
|Select|Info Dock|
