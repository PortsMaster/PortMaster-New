# Monk Tower

A coffee-break roguelike. Climb 20 floors of the cloister tower to retrieve the lost
manuscript, one turn at a time. Weapons wear out and break, so what you carry and when
you swap it matters more than what you fight.

## Controls

| | |
| --- | --- |
| D-pad / left stick | Move |
| B | Wait a turn |
| A | Pick up, interact, and confirm in menus |
| Y | Secondary action, where one is offered |
| L1 / R1 | Cycle the active weapon slot |
| Select | Put the d-pad on the panels for one action |
| Start | Open the menu |
