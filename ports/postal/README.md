Postal is a 1997 isometric shoot 'em up where players control the "Postal Dude" as he commits mass murder in Paradise, Arizona, progressing by killing a set percentage of armed hostiles per level.

This port is built using [initdream/postal-fixes](https://github.com/initdream/postal-fixes).

> [!IMPORTANT]
> This port does **not** include, and will never include, any copyrighted game
> assets. You must supply your own copy of the game files from GOG or Steam.

## Install

1. Download *Postal* from either GOG or Steam.
2. Locate the `res` folder and POSTAL.INI file inside your installed game directory.
3. Copy the `res` folder and the POSTAL.INI file and paste it inside the `postal/` folder in the `ports/` directory on your device.

## Configuration

Configuration settings can be managed in-game or by modifying the config files located at:

```
ports/postal/
```

## Controls

Standard controls for the game. Press Start+Select to exit.
