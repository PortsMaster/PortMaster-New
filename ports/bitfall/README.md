## Notes

Thanks to [Tom Eaves](https://tomeaves.itch.io/bitfall) (code and graphics) and Toby Dixon (music and SFX) for making BITFALL, a GBJAM 14 submission. Also thanks to Lamor26 for the packaging for PortMaster.

All rights to the game, artwork, and music belong to the original creators. This port contains only the wrapper script and configuration required to run the game on handheld devices.

The game uses a native resolution of 160x144 and a 4-color palette, which can result in borders depending on your device's screen.

## Installation

1. Download the game files (`bitfall_linux_x86_64.zip`) from [itch.io](https://tomeaves.itch.io/bitfall).
2. Extract the package and place the `BITFALL.pck` file inside the `gamedata/` folder of this port (`ports/bitfall/gamedata/`).
3. The Godot 4.7.1 and Weston 0.2 runtimes are installed automatically via PortMaster.

## Controls

| Button | Action |
|--|--|
| D-Pad | Move / Climb |
| A | Jump |
| B | Attack |
| Start | Pause / Menu |
| Select | Back / Map |
| Select + Start | Quit Game |
