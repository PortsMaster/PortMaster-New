## Notes

Thanks to [Tom Eaves](https://tomeaves.itch.io/bitfall) and Toby Dixon for making BITFALL. Also thanks to Lamor26 for the packaging for PortMaster.

All rights to the game, artwork, and music belong to the original creators. This port contains only the wrapper scripts and configuration required to run the game on handheld devices.

## Installation

1. Download the game files from [itch.io](https://tomeaves.itch.io/bitfall).
2. Extract the package and place the `BITFALL.pck` file inside the `gamedata/` folder of this port (`ports/bitfall/gamedata/`).
3. The Godot 4.7.1 runtime is installed automatically via PortMaster.

## Controls

| Button | Action |
|--|--|
| D-Pad | Move |
| A | Jump |
| B | Attack |
| Select | Map |
| Select + Start | Quit Game |
