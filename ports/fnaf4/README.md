Place FiveNightsatFreddys4.exe AND/OR FiveNightsatFreddys4 HalloweenEdition.exe into fnaf4/gamedata. On first launch you choose which version(s) to set up (doing one after the other/both may take
several hours). If both are installed, a menu lets you pick which one to play each time.

**For those who do not have headphones, cheats have been auto unlocked, make sure to enable danger indicator (X) to assist in gameplay)**

## Controls

| Button | Action |
|--|--| 
|start|enter|
|L1|flashlight|
|R1|close doors|
|left analog left|pan left|
|left analog right|pan right
|left analog up|move forward|
|left analog down|move backward|
|a|crawl/run|
|Y|mute call|
|X|Seal Vents|
|select|hide tips|
|b|house map cheat|
|y|fast night cheat|
|x|danger indicator cheat|
