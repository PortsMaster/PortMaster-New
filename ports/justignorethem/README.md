## Notes

Thanks to [Stranga Games](https://store.steampowered.com/search/?developer=Stranga%20Games) for developing this game. You can buy it on [Steam](https://store.steampowered.com/app/561770/Just_Ignore_Them/).

Runs on the AGS (Adventure Game Studio) engine, same setup as the My Big Sister port by Ganimoth.

## Controls

Point and click adventure — the d-pad drives a mouse cursor.

| Button | Action |
|--|--|
|Dpad / Left stick|Move cursor|
|L1 (hold)|Slow cursor (precision)|
|A|Left click (walk / interact)|
|B|Right click (examine)|
|X|Enter|
|Y|Space|
|Start / Select|Menu (Esc)|

## Install

Copy all game files from your purchased copy into the `gamedata` folder.

## Known quirks

- The save dialog asks for a typed save name; with no keyboard, confirm the empty name — saving and loading work fine with the unnamed slot.
