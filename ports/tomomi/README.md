## Controls

| Button | Action |
|--|--| 
|DPAD / Left Stick|Movement|
|A|Jump|
|B|Interact|
|X|Attack|
|Y|Sub-weapon|
|R1/L1|Skills / Zoom (on map)|
|Start|Confirm / Select. Start button also controls the hacking minigame|
|Select|Menu|
