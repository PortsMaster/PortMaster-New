## Controls

| Button | Action |
|--|--|
| D-Pad | Arrow Keys |
| Left Analog | Mouse Movement |
| A | Left Mouse Click |
| B | Right Mouse Click |
| X | Slow Mouse (Precision Mode) |
| Start | Enter |
| Back | Esc |
| L1/L2/R1/R2| ABCD Textinput | 

## Compile

```
git clone https://github.com/Cebion/blupimania-dev_pm.git
cd blupimania-dev_pm
mkdir build && cd build
cmake .. -DCMAKE_BUILD_TYPE=Release
make
```
