## Notes

Thanks to [Nathan Patrizi](https://github.com/nathan242/SDL-bullethell) for writing this fast-paced, hand-rolled SDL2 bullet-hell shooter with its own custom collision/animation engine.

## Controls

| Button | Action |
|--|--|
| D-Pad / Left Stick | Move |
| A | Fire |
| X | Shield (once charged) |
| L1 | Restart |
| Start | Pause |
| Back | Quit |

## Compile

git clone https://github.com/nathan242/SDL-bullethell.git
cd SDL-bullethell
make
