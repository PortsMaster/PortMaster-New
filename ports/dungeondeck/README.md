## Notes

Explore a dungeon in the form of a deck of cards! Collect rare items, build your own deck, and defeat the dungeon in this cozy card-based roguelike!

Download the latest version or free DEMO version of the game on steam and place all game files into the ports gamedata/ folder

Thanks Incinious for such a great deck roguelike.

Thanks Ganimoth for helping with issues getting the game running

## Controls

| Button | Action |
|--|--| 
|A|select/use|
|X|view|
|B|discard/cancel|
|Y|end turn|
|Start|pause menu|
