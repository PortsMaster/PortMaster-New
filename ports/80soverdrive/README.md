## Controls

| Button | Action |
|--|--| 
|D-pad / L-stick|Steer|
|A|Accelerate|
|B|Brake|
|X|Nitro|
|L1 / R1|Shift Gear|
|L2 / R2|Change Tracks|
|Start|Pause / Menu|
