## Controls

| Button | Action |
|--|--| 
|DPAD / Left Stick|Movement|
|A|Confirm / Jump|
|B/X/L1/R1|Spawn Totem|
|Y|Destroy Totem|
|L2/R2|Game speed (if enabled)|
|Select|Restart level|
|Start|Menu|
