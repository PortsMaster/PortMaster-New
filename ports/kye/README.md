## Kye
[PlayKye.com](https://playkye.com)

Kye is a current-gen remake of the Windows 3.1 puzzle game from 1992 by Colin Garbutt. Navigate each level and reach every diamond, experimenting to learn how the objects behave. Includes 500+ original and community levels and a level editor to make and share your own.

This port is ready to run: all game files are included. It runs the game's Android ARM64 build on the [Bogodroid](https://github.com/GeoffWoollams/Bogodroid) loader (a fork of Bogodroid NEO with Unity 6/7 support), so no extra downloads are needed.

Settings and progress are saved in the port's `conf` folder.
