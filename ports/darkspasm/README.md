## Controls

|Button|Action|
|-|-|
|DPAD / Left Stick|Movement|
|DPAD + Hotkey|Item Use (Slot 1/2/3)|
|A|Primary Fire|
|B|Secondary Fire|
|X/Y|Change Weapon|
|X/Y + Hotkey|Camera Control|
|L1/R1|Strafe|
|L2|Hotkey|
|R2|Walk|
|Start|Pause Menu / Confirm|
|Select / Start + Hotkey|Quick Save / Quick Load|
