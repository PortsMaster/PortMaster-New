A massive thank you to David McCandless and Leandro Barreto for creating the original 2002 "Helicopter Game" that inspired this entire project.

Huge appreciation goes to the talented artists who made this possible: [edomin](https://opengameart.org/content/helicopter-2) for the helicopter sprite, and [Luis Zuno (@ansimuz)](https://opengameart.org/users/ansimuz) for the incredible parallax backgrounds.

## Controls

| Button | Action |
|--|--| 
|A|Ascend [Starts the Game in Menu]|
|B|Back/Return|
|X|Opens Options in Menu|
|Y|Opens Leaderboard in Menu|
|Start|Pauses the Game [Starts the Game in Menu]|
|Select|Quits the Game in Menu|
|Start + Select|Quick Exit Hotkey|
|RB|Opens the Credits in Menu|
