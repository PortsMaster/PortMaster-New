## Controls

| Button | Action |
|--|--| 
|DPAD|Menu controls|
|Left Stick|Movement|
|Right Stick|Aim|
|A|Confirm|
|Y/A|Talk|
|L1|Special Attack|
|L2|Open Powerups|
|R1|Shoot|
|R2|Dash|
|Start|Pause|
