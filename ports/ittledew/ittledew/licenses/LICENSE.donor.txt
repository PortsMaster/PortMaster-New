The donor (donor/: Placeholder.x86_64 and Placeholder_Data) and the Unity 4 data converter (tools/unity4convert)

Teapot placeholder
  A Unity 4.7.2 rebuild of PortMaster's GameMaker placeholder game (the spinning teapot with "Something went
  wrong..."), made for PortMaster ports. Its scripts and shaders are own code (0BSD, below). The teapot mesh is
  the Utah teapot, taken from PortMaster's GameMaker placeholder (teapot_bezier0.norm). The text font is baked
  from Liberation Mono (SIL Open Font License 1.1, LICENSE.LiberationMono.txt).

Unity runtime
  Placeholder.x86_64 and the files in Placeholder_Data/Mono, Managed and Resources are Unity Technologies' Linux
  player and runtime, as the Unity 4.7.2 editor builds them for any game made with it.

Unity 4 data converter (tools/unity4convert)
  Own code (0BSD, below); source in tools/src/unity4convert. Its built-in layout reference (u4layouts.inc) holds
  Unity 4's serialized layouts (release type trees) derived from AssetRipper's TypeTreeDumps
  (https://github.com/AssetRipper/TypeTreeDumps, commit 20ba06e00e); the script data rules were measured.
