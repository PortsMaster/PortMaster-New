## Controls

| Button | Action |
|--|--| 
|start|enter/confirm|
|L1|left door|
|L2|left light|
|R1|right door|
|R2|right light|
|left analog left|A|
|left analog right|D|
|Y| mute call|
|A|open cameras|
|B|close cameras|
|D-pad|navigate cameras|
