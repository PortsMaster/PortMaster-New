## Notes

Thanks to [Ska Studios](https://ska-studios.com/games/charlie-murder/) for creating this game — a colorful, chaotic punk-rock beat-em-up where four-player co-op and a genuinely great soundtrack carry you through waves of undead enemies.

Thanks to [JohnnyonFlame](https://github.com/JohnnyonFlame) for the FNA/Mono patching tooling and workflow (FNAPatches, MMLoader, ASTC texture repacking) that this port's setup process is built on.

Thanks to the PortMaster team for the tools and infrastructure that make ports like this possible.

## Controls

| Key | Action |
|--|--|
| A | Grab / Cancel |
| B | Jump / Accept |
| X | Heavy Attack |
| Y | Normal Attack |
| L1 | Use Cooldown Item |
| R1 | Use Health Item |
| L2 | Block |
| R2 | Anar-Chi |
| L3 | Defib Left |
| R3 | Defib Right |
| D-Pad Up | Not Twitter |
| D-Pad Down | Camera |
| D-Pad Left | Releveler |
| D-Pad Right | Email |
| Select | Inventory |
| Start | Pause / Confirm |
