OpenChaos PortMaster third-party notices
========================================

This package does not include Urban Chaos game data. Users must provide their
own legally obtained game resources.

This package includes the OpenChaos executable and dynamically linked shared
libraries under libs.aarch64/. License texts and copyright notices for bundled
components are included in this directory when the release package is built.

Bundled runtime components include:

- OpenChaos: MIT License
- SDL3 shim from bmdhacks SDL sdl2-backend branch: SDL license text
- FFmpeg libraries: see ffmpeg-copyright.txt
- ALSA libraries: see alsa-copyright.txt
- OpenAL Soft: see openal-soft-copyright.txt
- fmt: see fmt-copyright.txt
- nlohmann-json: see nlohmann-json-copyright.txt

The PortMaster package links these libraries dynamically. Source and build
details are represented by the repository build files, vcpkg manifest/triplets,
and the SDL shim source referenced by the PortMaster build instructions.
