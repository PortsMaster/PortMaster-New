## Notes

Download the 27mb game version from the [itch.io](https://trashy-rascal-studios.itch.io/lasagna-boy-classic) website. Extract the files and place them in the ports/barrelroll/assets directory.

Special thanks for [Trashy Rascal Studios](https://trashy-rascal-studios.itch.io) for making this wonderful game!

## Controls

| Button | Action |
|--|--| 
|A|Confirm|
|D-PAD | LEFT JOYSTICK|Move/Action|
|SELECT | START|Quit Game|
