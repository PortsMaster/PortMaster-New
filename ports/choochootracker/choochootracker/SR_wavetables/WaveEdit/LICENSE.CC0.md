# WaveEdit Online banks

Source: <https://github.com/smpldsnds/wavedit-online>, commit
`1a8d80f7a062f36eca212f92f24f2ca6329b88ff`.

The upstream project states that all included wavetables are dedicated to the
public domain under CC0 1.0 Universal. Each WAV contains 64 frames of 256
samples and is suitable for the BYOWTBL SR wavetable loader.
