ADDITIONAL PRESET COLLECTIONS — 2026-10-05

16bit-station.wopn: NeoSoundFonts, CC0-1.0. Converted supported melodic
programs into Genesis native instruments. Source note offsets and fixed
percussion keys are excluded; source blanks are not presets.

ymulator.opm: YMulator-Synth contributors, GPL-3.0. Converted supported
programs into Arcade native instruments. Noise-dependent and silent-carrier
programs are excluded. The complete preferred source bank and its full license
are included here; these presets retain their source license.

emu2413.c: Mitsutaka Okazaki and credited tone-table contributors, MIT.
Only melodic tone-table data is used for OPLL/VRC7. No emulator code is compiled
from this file. Exact duplicate tones are excluded within each engine.

sources.json records pinned revisions, upstream URLs and SHA-256 hashes.
Each original source has an accompanying .LICENSE file. expansion.py and
four_op.py document the conversion and authored additional OPLL programs;
ChooChoo-authored code/programs use the project MIT license. No game or song
recordings are included or claimed as the source of these new programs.
Detailed conversion exclusions are in instruments/FACTORY/expansion-manifest.json.
