ChooChooTracker 16x24 font collection

Open Settings -> Load font -> Pixel16x24 inside the fonts directory.
Select one of these four files:

01_TechMonoAudit.cnfont: Share Tech Mono, rasterized monochrome at 22 px.
  Converted family name: TechMonoAudit. 'Share' is a Reserved Font Name,
  so the derivative filename and internal name do not use it.
02_DepartureMono.cnfont: Departure Mono 1.500, rendered unhinted at its
  native 11 px grid and enlarged exactly 2x. No smoothing or distortion.
03_Spleen.cnfont: Spleen 2.2.0, original 12x24 BDF pixels with padding.
04_Cozette.cnfont: Cozette v.1.30.0, native BDF pixels with padding.
  This is visibly smaller: the full ASCII ink height is 13 px, so doubling
  it would require 26 px and would not fit the 24 px cell. No glyphs were
  clipped or individually moved to force a larger size.

Every file has one 16x24 resolution for a 640x480, 40x20 grid.
The renderer's font format has exactly 95 ASCII slots (32-126), all supplied.
Only space is blank. Punctuation, table pitch '='/'~', playback '<'/'>',
brackets, bars, accents, and all other printable ASCII are present.
There are no additional Unicode/icon slots in this format. Extra upstream
Unicode coverage is outside what this renderer supports.

All glyphs retain their relative bearings and one baseline per font.
Coverage, byte lengths, names, line lengths, bit order, no pixel loss,
O/0 and I/1/l differences, and decoded bitmap previews were checked locally.
These previews are not screenshots of the running handheld app.
Installation does not select a font or change any settings.
