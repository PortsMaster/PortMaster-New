USER library for opl2.
Accepted source formats: CNI, WOPL, OPLI, WOPLX, SBI, FUI. Compatible subsets only; see USER_MANUAL.
Copy files, ZIP collections or your own subfolders here. No TSV is required.
Choose USER in the instrument bank/preset menu to browse and audition.
Unsupported features report a reason and leave the current instrument intact.
Preserve personal files during updates; do not include them in shared builds.
