YOUR PRESETS AND COLLECTIONS

Put your own presets, ZIP packs and subfolders in the matching engine folder.
Choose USER in that engine's bank or preset menu to browse them.
All engines accept compatible CNI. See each folder's README for source formats.
SYX, TFI, OPM, WOPL/WOPLX/OPLI/SBI, FUI, DMP and GoatTracker INS are
supported by the relevant engines, with explicit feature/version limits.
SID-Wizard SWI and SID music files are not supported instrument formats.
ZIP packs may contain subfolders. No catalog or TSV is required.

Back up this folder with your songs. Personal files belong here, not in FACTORY.
