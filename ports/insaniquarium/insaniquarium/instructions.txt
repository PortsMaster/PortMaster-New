Insaniquarium Deluxe - PortMaster
=================================

This port does NOT include the game. It is the executable only; the game
files come from a copy you own (Steam).


WHERE TO PUT THE GAME FILES
---------------------------

Copy these six folders from your Insaniquarium Deluxe installation into this
folder, next to this file:

    data
    images
    music
    properties
    sounds
    fishsongs

When it is done, this folder should look like:

    ports/insaniquarium/
        Insaniquarium          <- comes with the port
        insaniquarium.ini      <- comes with the port
        data/                  <- you copy this
        images/                <- you copy this
        music/                 <- you copy this
        properties/            <- you copy this
        sounds/                <- you copy this
        fishsongs/             <- you copy this

On Steam the files are in:

    steamapps/common/Insaniquarium Deluxe/

The game will not start without them and will tell you so.


IF IT SAYS A FILE IS MISSING THAT IS CLEARLY THERE
--------------------------------------------------

Windows treats "Image.gif" and "image.gif" as the same file. Linux does not,
and some cards store files either way.

The port already looks for a name that differs only in capitals, so this
should not come up. If it still does, log.txt names the exact file it wanted;
renaming yours to match that spelling fixes it.


CONTROLS
--------

    Left stick / D-pad    Move the pointer
    A                     Left click - feed, collect coins, shoot
    B                     Right click - release a pet, cancel
    L1 / R1               Move the pointer slowly
    Y                     Collect every coin at once, if Auto Collect is on
    Start                 Enter
    Select                Escape

Auto Collect is switched off, in Options. It asks once before turning on,
because it does make the coin-collecting pets much less useful.


SAVES
-----

Profiles and high scores live in:

    ports/insaniquarium/conf/

They stay inside the port folder, so deleting the port removes them and
copying the folder to another card keeps them.


IF SOMETHING GOES WRONG
-----------------------

The port writes ports/insaniquarium/log.txt every time it runs. If it fails
to start, that file records the device, the firmware and the reason. Sending
it with a bug report is usually enough to identify the problem.
