## Notes

Thanks to Toys for Bob and the UQM project for creating the game and its source code, and for releasing it under free licences.

This binary was built from UQM 0.8.0 source for aarch64. The source is available from the original project.

Thanks to pervertedPistachio for the packaging for PortMaster.

Install the Ur-Quan Masters Lite port, then launch it from the Ports menu. The 3DO music is included. Speech needs the voice pack, which is not included in this build.

## Controls

| Button | Action |
|--|--| 
|X button|Select|
|O button|Back|
|D-pad Up / Down / Left / Right|Move through menus|
