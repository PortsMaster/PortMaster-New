## Compile

Source: https://github.com/justaporter/Google-Dino-Love2D

### Linux / macOS

    git clone https://github.com/justaporter/Google-Dino-Love2D
    cd Google-Dino-Love2D
    zip -9 -r ../DinoLove2D.love main.lua conf.lua sprite.png hit.ogg jump.ogg reached.ogg LICENSE LICENSE-chromium-dino.txt

If you downloaded the ZIP instead, run `unzip Google-Dino-Love2D-main.zip` and `cd Google-Dino-Love2D-main`, then run the zip command above.

### Windows

1. Extract the downloaded zip.
2. Open the extracted folder and select main.lua, conf.lua, sprite.png, the three .ogg files and both LICENSE files.
3. Right click > Send to > Compressed (zipped) folder.
4. Rename the zip to DinoLove2D.love.

Opening the .love as an archive should show main.lua straight away, with no folder in front of it.
