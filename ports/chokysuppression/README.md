## Controls

| Button | Action |
|--|--| 
|DPAD / Left Stick|Movement|
|A|Confirm / Primary Weapon|
|B|Back / Secondary Weapon|
|X|Pause / Exit|
|L1/L2/R1/R2|Strafing|
