## Controls

|Button|Action|
|-|-|
|D-PAD / Left Stick|Directional movement|
|A|Sword / Cancel|
|B|Interact / Talk|
|X|Fireball|
|Y|Jump|
|L1 / R1|Change Inventory Screen|
|L2|Run|
|R2|Quick Item|
|Start|Menu|
