
                          LGeneral Scenario Pack
                          ======================

About
-----

﻿This is a collection of converted Panzer General scenarios created by
various authors. Most conversions have been done by Vadim B. Balashoff.

Just copy the directories to your LGeneral installation. In Linux it is 
usually /usr/local/share/games/lgeneral and in Windows the same directory
where the binary is located.

The directory 'info' contains additional information about most scenarios as 
text files with the same name as the respective scenario.

Issues
------

* Victory conditions not implemented for Demjansk: Axis needs to hold/capture
  Staraja Russa, Ramoujevo, Lyohkovo, Demjansk and Kholm for victory
* Victory conditions not implemented for Denmark: Denmark needs to hold german
  pressure until April 22th 1940... whatever this means
* Victory conditions not implemented for Papagos_Plus: The Wing side wins ONLY
  if it scores an EARLY victory... whatever this means
* Carentan shows wrong terrain description in normal view but correct one on
  strategic map

Enjoy!
