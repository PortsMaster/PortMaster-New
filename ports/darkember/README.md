## Notes

Thanks to [kindlegames](https://kindlegames.itch.io/) for creating **Dark Ember**, a pixel-art bonfire-defense roguelike.

All rights to the game, artwork, and music belong to the original creators. This port contains only the wrapper script and configuration required to run the game on handheld devices.

## Installation

Download the Linux ARM64 build (`DarkEmber-v0.1.22-windows.zip`) from [itch.io](https://kindlegames.itch.io/dark-ember) and extract its contents into the `darkember` folder.

1. Download the game files (`DarkEmber-v0.1.22-windows.zip`) from [itch.io](https://kindlegames.itch.io/dark-ember).
2. Extract the package and place the `DarkEmber.exe` file inside the `gamedata/` folder of this port (`ports/darkember/gamedata/`).
3. The Godot 4.7.1 and Weston 0.2 runtimes are installed automatically via PortMaster.

## Controls

| Key | Action |
|--|--|
| D-Pad / Left Stick | Move |
| A | Roll |
| B | Torch |
| X | Feed the Fire / Sit Down |
| Y | Repair |
| L1 | Previous Weapon |
| R1 | Next Weapon |
| L2 | Weapon Special |
| R2 | Attack |
| D-Pad Up | Drink Potion |
| D-Pad Left | Previous Potion |
| D-Pad Right | Switch Potion |
| D-Pad Down | Building |
| Select | Book |
| Start | Menu |
