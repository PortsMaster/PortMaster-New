## Controls

| Button | Action |
|--|--|
|D-PAD|Move|
|A|Action / Dodge|
|B|Swing weapon|
|B (Hold)|Charge weapon|
|X|Shoot pistol|
|Y|Heal|
|START|Pause & Save|
