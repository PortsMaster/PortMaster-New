## Controls

| Button | Action |
|--|--| 
|DPAD / Left Stick|Move|
|Right Stick|Aim|
|A / L2|Jump / Confirm|
|B|Back|
|X / R2|Attack|
|Y|Join Second Player / Equipment Screen|
|Start|Pause|
