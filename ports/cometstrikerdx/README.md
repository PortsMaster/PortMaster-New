## Controls

| Button | Action |
|--|--| 
|D-pad / L-stick|Movement|
|R1 / R2|Boost Attack|
|X / R-stick Left|Shoot Left|
|A / R-stick Right|Shoot Right|
|Start|Pause / Menu|
