## Controls

| Button | Action |
|--|--| 
|D-pad|Move/Aim|
|Left Stick|Move/Aim|
|Right Stick|Juke/Dive|
|A|Juke/Hand off/Bullet|
|B|Confirm/Throw|
|Y|Time out/Audible/Scramble |
|X|Activate Sim|
|R1|Next Page|
|L1|Previous Page|
|Select|Scramble|
|Start|Pause|
