## Notes

Thanks to FLENT ([foxlinked](https://foxlinked.itch.io/vertsky)) for making VertSky, a roguelite vertical arcade shooter.

According to the creators, VertSky was made with AI assistance (code, graphics, sounds and text, built with Grok Bot under the direction of foxlinked).

All rights to the game, artwork, and music belong to the original creators. The game is included in this port with the permission of the creators (version `VertSky-1.0.19`).

The game supports 1 or 2 players (local co-op). Player 2 needs a second gamepad. The screen layout is picked automatically (16:9, 4:3 or 3:2) and can be changed in the game's options.

## Installation

**Ready to run!** The game is already included in this port (`ports/vertsky/gamedata/`), so no additional files are required. The Godot 4.7.1 and Weston 0.2 runtimes are installed automatically via PortMaster.

**Note:** Depending on the device and operating system, the initial boot or launch might take longer (up to 1–2 minutes). Please be patient.

## Controls

| Button | Action |
|--|--|
| D-Pad / Left Stick | Move |
| A | Fire (hold) |
| B | Bomb (press again to detonate) |
| X | Dash |
| Y | EXTRA tool |
| Start | Pause |
| Select | Auto-fire on / off |
| D-Pad / Left Stick + A | Pick a card |
