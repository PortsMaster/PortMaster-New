## Controls

| Button | Action |
|--|--|
| D-Pad | Move / Rotate / Drop (in-game) |
| Left / Right Stick | Move cursor (menus) |
| A | Click / Confirm (menus) |
| B / X | Hold to slow cursor (menus) |
| Start | Confirm / Menu |
| Start + D-Pad Down | Text entry for high-score name |
| Select | Pause |

## Compile

git clone https://github.com/Cebion/CandyCrisis_pm.git
cd CandyCrisis_pm
mkdir build && cd build
cmake ..
make
