## Controls

| Button | Action |
|--|--| 
|R-Stick|Camera|
|L-Stick Left Right| Turn selected face|
|L-Stick Up Down| Turn selected middle face|
| D-Pad Up | Zoom in |
| D-Pad Down | Zoom out |
| D-Pad Left | Change cube |
| D-Pad Right | Change cube |
|L1/L2|Turn left face|
|R1/R2|Turn right face|
