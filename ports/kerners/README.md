## Notes

Kerners is a free word puzzle game by bokoyoss. Thanks for playing!

* [Kerners on itch.io](https://bokonon-yossarian.itch.io/kerners)

## Controls

| Button | Action |
|--|--|
| D-pad / Left Stick | Move |
| A | Select / Place |
| B | Back |
| X | Sort |
| Y | Next puzzle |
| L1 / R1, L2 / R2 | Rotate drawer |
| Start / Select | Settings |
