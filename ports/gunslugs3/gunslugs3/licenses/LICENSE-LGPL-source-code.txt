Corresponding source code for the LGPL-covered runtime components

The Gunslugs 3 PortMaster package distributes the LGPL-covered runtime libraries as separate replaceable files. These exact upstream source distributions correspond to the bundled JLayer, JOrbis, and OpenAL Soft versions:

JLayer 1.0.1-gdx source JAR:
https://repo.maven.apache.org/maven2/com/badlogicgames/jlayer/jlayer/1.0.1-gdx/jlayer-1.0.1-gdx-sources.jar

JOrbis 0.0.17 source JAR:
https://repo.maven.apache.org/maven2/org/jcraft/jorbis/0.0.17/jorbis-0.0.17-sources.jar

OpenAL Soft 1.23.1 source archive:
https://openal-soft.org/openal-releases/openal-soft-1.23.1.tar.bz2

The matching source archives are pinned by SHA-256 in tools/source-lock.json and kept in tools/third-party-sources/ in the source tree. The corresponding license texts are LICENSE-LGPL-2.1.txt and LICENSE-OpenAL-Soft.txt.
